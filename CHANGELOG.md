## [0.3.0] - 2026-07-08

Initial tracked release of MavisX — an all-in-one desktop toolkit for IT and
homelab work: uptime monitoring, incident tracking and alerting, an SSH terminal,
SFTP file manager, Docker manager, network toolkit, web viewer, and an encrypted
credential vault, plus cloud auth and Lemon Squeezy billing (Free / Pro).
